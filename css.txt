CSS Knowledge Pack (Part 1) — Foundations + Practical Notes
============================================================

This file consolidates foundational CSS learning content and practical notes
for web and wiki environments.

------------------------------------------------------------
1) CSS Introduction
------------------------------------------------------------
What is CSS?
- CSS is the language we use to style a web page.
- CSS stands for Cascading Style Sheets.
- CSS describes how HTML elements are displayed on screen, paper, or other media.
- CSS saves work by controlling layout for many pages at once.
- External stylesheets are stored in `.css` files.

Why Use CSS?
- Define design, layout, and device/screen-size variations.
- Reuse one stylesheet across many pages.

Example:
body {
  background-color: lightblue;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: verdana;
  font-size: 20px;
}

------------------------------------------------------------
2) CSS Syntax
------------------------------------------------------------
A CSS rule has:
- selector
- declaration block

Each declaration has:
- property
- value

Example:
p {
  color: red;
  text-align: center;
}

Notes:
- declarations are separated by semicolons
- declaration blocks use curly braces `{}`

------------------------------------------------------------
3) CSS Selectors (basic map)
------------------------------------------------------------
Selector groups:
1. Simple selectors (name, id, class)
2. Combinator selectors
3. Pseudo-class selectors
4. Pseudo-element selectors
5. Attribute selectors

Element selector:
p {
  text-align: center;
  color: red;
}

ID selector:
#para1 {
  text-align: center;
  color: red;
}

------------------------------------------------------------
4) How to Add CSS
------------------------------------------------------------
Three ways:
1. External CSS (`<link rel="stylesheet" href="mystyle.css">`)
2. Internal CSS (`<style>` in `<head>`)
3. Inline CSS (`style="..."`)

External example (HTML):
<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="mystyle.css">
</head>
<body>
<h1>This is a heading</h1>
<p>This is a paragraph.</p>
</body>
</html>

External file example (`mystyle.css`):
body {
  background-color: lightblue;
}

h1 {
  color: navy;
  margin-left: 20px;
}

Important:
- no space between value and unit: `20px` (not `20 px`)

------------------------------------------------------------
5) CSS Comments
------------------------------------------------------------
CSS comment syntax:
/* comment */

Examples:
/* single-line */

p {
  color: red; /* inline comment */
}

/* multi-line
   comment */

Notes:
- Comments are ignored by browsers.
- HTML comments (`<!-- -->`) and CSS comments can both appear in one document.

------------------------------------------------------------
13) CSS Box Model
------------------------------------------------------------
Each element box has:
1. content
2. padding
3. border
4. margin

Total width formula:
width + left padding + right padding + left border + right border

Total height formula:
height + top padding + bottom padding + top border + bottom border

Note:
- margin affects occupied page space, but is outside element box dimensions.

36) Styling Form Inputs
- Common properties: width, padding, margin, border, border-radius, background-color, color, font-size.
- Focus styles with `:focus`.
- Optional icon in input via `background-image` + `background-position` + left padding.
- Animated focus width via `transition`.

Examples:
input[type=text]:focus {
  background-color: lightblue;
}

input[type=text]:focus {
  border: 3px solid #555;
}

input[type=text] {
  background-color: white;
  background-image: url('searchicon.png');
  background-position: 10px 10px;
  background-repeat: no-repeat;
  padding-left: 40px;
}

input[type=text] {
  transition: width 0.4s ease-in-out;
}

input[type=text]:focus {
  width: 100%;
}

40) CSS Inheritance
- Inherited properties: typically text-related (color, font-size, etc.).
- Non-inherited: typically box/layout-related (border, margin, padding, width, height).
- Force inheritance with `inherit`.

Example:
strong {
  border: inherit;
}

41) CSS Specificity and !important
Specificity hierarchy:
- inline styles (highest practical)
- id selectors (1-0-0)
- class/attribute/pseudo-class (0-1-0)
- element/pseudo-element (0-0-1)
- universal `*` and `:where()` (0-0-0)

`!important` overrides normal cascade and should be used sparingly.

42) CSS Math Functions
- `calc()`
- `max()`
- `min()`
- `clamp()`

Examples:
#div1 {
  width: calc(100% - 100px);
  height: calc(30vh + 50px);
}

#div1 {
  width: max(50%, 300px);
}

#div1 {
  width: min(50%, 300px);
}

h2 {
  font-size: clamp(1.5rem, 5vw, 3rem);
}

43) CSS Performance Optimization
- Prefer simple selectors.
- Avoid unnecessary universal selector usage.
- Avoid inline styles when possible.
- Prefer `<link>` over `@import` for CSS loading.
- Use shorthand properties.
- Reduce heavy/unused animations.
- Prefer performant animation properties (`transform`, `opacity`, `filter`).
- Combine/minify/cache stylesheets.

44) CSS Accessibility Styling
- Maintain high color contrast.
- Use readable fonts, proper size, and line-height.
- Keep visible focus indicators.
- Do not remove focus outline without replacement.
- Respect user preferences: `prefers-reduced-motion`.

Example:
a:focus, button:focus, input:focus {
  outline: 2px solid orange;
}

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

56) CSS Animations
Core pieces:
- `@keyframes`
- `animation-name`
- `animation-duration`
- optional timing props: delay, iteration-count, direction, fill-mode, timing-function, play-state

Examples:
@keyframes myAnimation {
  from { background-color: red; }
  to { background-color: yellow; }
}

div {
  animation-name: myAnimation;
  animation-duration: 4s;
}

@keyframes myAnimation {
  0%   {background-color:red; left:0; top:0;}
  25%  {background-color:yellow; left:200px; top:0;}
  50%  {background-color:blue; left:200px; top:200px;}
  75%  {background-color:green; left:0; top:200px;}
  100% {background-color:red; left:0; top:0;}
}

animation shorthand example:
div {
  animation: myAnimation 5s linear 2s infinite alternate;
}

PART 4 — Final pack: Flex items + responsive flexbox + CSS references
------------------------------------------------------------

The CSS Flex Items Properties
The following table lists all the CSS Flex Items properties:

Property	Description
align-self	Specifies the alignment for a flex item (overrides the flex container's align-items property)
flex	A shorthand property for the flex-grow, flex-shrink, and the flex-basis properties
flex-basis	Specifies the initial length of a flex item
flex-grow	Specifies how much a flex item will grow relative to the rest of the flex items inside the container
flex-shrink	Specifies how much a flex item will shrink relative to the rest of the flex items inside the container
order	Specifies the order of the flex items inside the container

CSS Responsive Flexbox
Responsive Flexbox
You learned from the CSS Media Queries chapter that you can use media queries to create different layouts for different screen sizes and devices.

For example, if you want to create a three-column layout for large screen sizes, and a one-column layout for small screen sizes (such as phones), you can change the flex-direction from row to column at a specific breakpoint (600px in the example below):

Example
.flex-container {
  display: flex;
  flex-direction: row;
}

.flex-item {
  background-color: #f1f1f1;
  padding: 10px;
  font-size: 30px;
  text-align: center;
  width: 100%;
}

/* Make a one column-layout instead of three-column layout */
@media (max-width: 600px) {
  .flex-container {
    flex-direction: column;
  }
}

Another way is to change the percentage of the flex property of the flex items to create different layouts for different screen sizes. Note that we also have to include flex-wrap: wrap; on the flex container for this example to work:

Example
.flex-container {
  display: flex;
  flex-wrap: wrap;
}

.flex-item {
  background-color: #f1f1f1;
  padding: 10px;
  text-align: center;
  font-size: 30px;
  flex: 33.3%;
}

/* Make a one column-layout instead of a three-column layout */
@media (max-width: 600px) {
  .flex-item {
    flex: 100%;
  }
}
